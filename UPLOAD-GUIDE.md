# Upload Guide

Upload the CONTENTS of this folder to your GitHub repository root:

- README.md
- INTERVIEW-NOTES.md
- .gitignore
- docs/
- images/

Recommended method:
1. Extract the ZIP.
2. Open the extracted folder.
3. In GitHub's Upload files page, drag ALL of the items above into the upload box.
4. Wait until all files finish uploading.
5. Commit message: `Add complete Wazuh SOC investigation portfolio project`
6. Click Commit changes.

Do not upload the outer `WAZUH-SOC-PORTFOLIO-UPLOAD-READY` folder itself if you want README.md to display on the repository homepage.
